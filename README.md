**Bounty Board** adalah aplikasi manajemen buronan bertema *Western* yang dibuat untuk sebuah "Guild". Aplikasi ini memungkinkan para *Hunter* melihat daftar buronan, mengirim laporan buronan baru, serta menyediakan panel *Guild Master* (Admin) untuk mengelola status buronan dan menyetujui kontrak.

Aplikasi menggunakan **React (Vite)** untuk frontend, **Express.js** sebagai backend API, dan **Supabase** sebagai database, autentikasi, serta penyimpanan file.

---

## ✨ Fitur Utama

### 🌍 Public & Hunters
- **Wanted Board:** Menampilkan daftar buronan dengan gaya poster "WANTED".
- **Captured Log:** Arsip buronan yang telah ditangkap.
- **Search & Filter:** Pencarian berdasarkan nama/kejahatan serta pengurutan berdasarkan nilai *bounty*.
- **Submit Bounty:** Hunter dapat mengajukan buronan baru (status awal *pending*).
- **Profile Management:** Mengelola username dan avatar dengan fitur *image cropping*.

### 🛡️ Guild Master (Admin)
- **Approval Desk:** Review dan aksi Approve/Reject terhadap pengajuan buronan.
- **Full CRUD:** Kelola data buronan secara lengkap.
- **Status Management:** Menandai buronan menjadi *Captured* atau mengembalikannya ke *Wanted*.

### 📱 Fitur Teknis
- **PWA Support** (Vite PWA)
- **Secure Auth** dengan Supabase
- **Image Processing** untuk avatar dan poster buronan
- **Responsive Design** bertema kayu dan kertas

## 1. Setup Database (Supabase)

```sql
-- Tabel Buronan
create table public.fugitives (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  alias text,
  description text,
  crime text,
  bounty_amount numeric,
  image_url text,
  last_seen text,
  status text default 'pending'
);

-- Tabel Profil User (Hunter)
create table public.profiles (
  id uuid references auth.users not null primary key,
  updated_at timestamp with time zone,
  username text unique,
  avatar_url text,
  role text default 'hunter'
);

-- Storage Bucket: avatars (Public)
```

## 2. Konfigurasi Backend (`bounty-api`)

```bash
cd bounty-api
npm install
```

`.env`:
```env
PORT=3000
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-anon-key
```

Jalankan server:
```bash
npm start
```

---

## 3. Konfigurasi Frontend (`bounty-board`)

```bash
cd bounty-board
npm install
```

`.env`:
```env
VITE_API_URL=http://localhost:3000
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

Jalankan:
```bash
npm run dev
```

## 🔑 Role & Akses

User baru otomatis: `hunter`.

Membuat user menjadi admin:
1. Supabase → Table Editor → `profiles`
2. Ubah `role` → `admin`
3. Login ulang
